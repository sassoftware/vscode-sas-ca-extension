## [v1.0.2] - 2026-08-21

### Added

Added support for the Clinical Acceleration Workspace including:

- View workspace
- Open a workspace file
- View checked out status of file in the repository
- Create new folder in the workspace
- Rename a file or folder in the workspace
- Delete content from the workspace
- Upload a file or files to the workspace
- Download content from the workspace
- Upload and expand zip file to workspace
- Copy a folder from the repository to the workspace
- Copy a folder structure from the repository to the workspace
- Copy a specific version of a file from the repository to the workspace
- Check in a new file to the repository
- Copy the latest version of a file from the repository to the workspace
- Check existing file into the repository
- Undo check-out from workspace or repository
- Check out file from the repository
- Display synchronization status of a file in the repository
- Create and save a new file to workspace
- Compare a repository to workspace file
- Compare two files in the workspace
